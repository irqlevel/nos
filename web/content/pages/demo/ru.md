Задача видео — запустить несколько виртуальных машин с Linux на разных узлах кластера: их диски на отказоустойчивом хранилище, а сами машины в общей приватной сети. Это одна сессия в панели управления небольшого кластера nos из трёх хостов. Первый — сервер Intel EX44 в Hetzner, nos на нём работает прямо на железе. Два других — экземпляры nos в виртуальных машинах KVM на втором сервере, AMD AX41. Видео только подрезано: вырезаны ожидание загрузки образа и ожидание, пока машина загрузится. Всё остальное показано так, как было.

## Что в видео

1. **Хосты.** Все три загружены в nos. Панель обращается к API каждого хоста по TLS с взаимной проверкой ключей и видит все три.
2. **Образ по публичной ссылке.** Хост скачивает облачный образ Debian 13, переводит его из qcow2 и записывает в NBS, блочное хранилище кластера. Там образ замораживается только для чтения, а машины делаются из его клонов.
3. **Сеть между хостами.** vnet даёт машинам на разных хостах общую подсеть, шлюз и выход в интернет. Состояние сетей кластера хранится на каждом хосте и согласуется через Raft.
4. **Две машины на двух хостах.** Диск каждой — клон образа. Обе машины в новой сети, за фаерволом кластера, который пускает внутрь только пинг из этой сети. Пароль из формы cloud-init выдаёт пользователю образа.
5. **Хранилище зелёное.** Каждый чанк каждого тома лежит на трёх хостах, а метаданные NBS согласуются через Raft, поэтому хранилище продолжает работать, когда хост выходит из строя.
6. **Консоли и пинг.** Последовательные консоли машин транслируются в панель. Входим на одну машину и пингуем другую. Пакеты идут через шифрованный туннель между хостами: ChaCha20-Poly1305 на ассемблере CRYPTOGAMS.

## Текст ролика

nos — маленькая ОС для серверов. Её ядро на C++ небольшое, его можно прочитать и проверить целиком. Всё остальное — драйверы устройств, гипервизор, файловые системы, сеть и хранилище — написано на безопасном Rust. Он помогает исключить обращения за границы памяти и гонки данных — ошибки, типичные для кода на C в Linux.

В этом демо запустим несколько виртуальных машин с Linux на разных узлах кластера: их диски — на отказоустойчивом хранилище, а сами машины — в общей приватной сети.

Это панель управления. Все три хоста кластера загружены в nos, и панель видит каждый. Сначала образ виртуальной машины по публичной ссылке: облачный Debian 13. Хост скачал образ и записал его в блочное хранилище NBS. Образ готов.

Теперь виртуальная сеть, общая для машин на разных хостах: подсеть, шлюз и выход в интернет. Состояние сетей хранится на каждом хосте и согласуется через Raft, так что сеть переживает отказ хоста.

Первая машина на этом хосте: из образа, в новой сети, с паролем для входа и фаерволом, который пускает внутрь только пинг. Машина создана. Запускаем её прямо из списка. Вторая машина — на другом хосте кластера: тот же образ, та же сеть и тот же фаервол. Обе машины видны в панели и уже работают.

Хранилище зелёное. Каждый блок лежит на трёх хостах, а метаданные согласуются через Raft, поэтому отказ хоста хранилищу не страшен.

Консоль машины: Debian загрузился. Теперь консоль первой машины. Входим под пользователем debian. И пингуем вторую машину на другом хосте. Пакеты идут через шифрованный туннель между хостами.
